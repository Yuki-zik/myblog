# 白纸与便签精修 · 2026-10-20

## 依据与范围

用户截图指出首页近期标签换行错位、漫游方框堆叠、作者页比例不协调，同时明确认可首页挂板/便签式漫游入口。设计沿用该入口的薄纸边、轻阴影、橙色标注，只在需要聚焦的内容上使用浮起纸面。

- 首页：日期、标签各用固定列，标题独立，长标签不会改变其他行的对齐。手机元数据与标题分行。
- 漫游：三块等重卡片改开放编号路线。真实文章停靠点保留薄便签，类型与视图以文字下划线表达状态；当前条目预览是主要浮纸面。图谱数据、搜索、筛选、键盘、链接与无 JS 入口保持。
- 作者：头像、身份、使命与统计组成一张档案纸，原头像保留；研究方向按编号、摘要与要点对齐，论文标题、年份和状态形成清晰层级。真实资料、计数和 PostCard 保留。
- 首页挂板入口、胶囊导航、文章和论文阅读系统未修改。

## 视觉版本

基线：`21d0ea4e0e26c2d8f6ad936a715ba867365beb79`。线上基线实际从 a-znk-blog.vercel.app 跳转到 `https://a-znk.com`；本次沿用现有域名和发布集成，不调整域名。

- `before-*`：正式站修改前，1440×1000、浅色。全页旧图用于留档；下方懒加载图片未全部滚动加载，不作为图片正确性依据。
- `reference-gateway.png`：用户认可的首页挂板入口，保持不变。
- `v1-*`：初版构建截图，桌面1440×1000、手机390×1000，浅/暗色。实际检查发现手机停靠数竖排过小，进入 v2 修正。
- `v2-*`：停靠计数改横向题签；链接桌面15.2px/手机15px，保持44px触控。其余 author/home v1 即采用版。
- `production-*`：发布后实际站点回读与截图。

`captures.json` 记录各文件 sha256；工作区源文件哈希记录采用实现，避免依赖截图文件的提交自引用。

# 封面展示：原图、标题比例与图版层次

2026-10-18。用户明确保留所有原图，只优化大小、位置与展示层次。

## 设计依据

上一版宽屏封面280px，被放进旁注宽度的列，标题占满正文列，导致封面更像缩略图。新版本保持标题卡总宽，以1.45:1分配文字与封面、32px间距；1440px屏幕封面约410px，超宽屏最多440px。标题、摘要和元信息仍先于图片出现在DOM中；单栏居中最大400px，手机贴合可用内容宽度。

层次来自6px纸边、1px轮廓、5×7px偏移底纸和柔和阴影，橙色定位角呼应图纸语言。弱化模糊光晕，不改变图像内容、色彩或裁切。所有原始封面、正文、目录和旁注控制器保持原样。主图在正常流中撑开页头，旁注继续随正文引用自动定位。

# 全站图版与轻交互 · 2026-10-21

用户要求以适量经典图像丰富全站视觉，并增加一点交互，而不是只修改作者页的一个局部。原则与来源详见 ../../editorial-imagery.md。

## 实施

五幅可核验的公共领域历史图版，配对主题目录、主题说明、作者研究方向、概念与论文列表的独立历史参考区。共享 EditorialFigure 提供本地图像、图注/年代、常显来源及可展开说明；复用现有 ImageViewer 的键盘、原始尺寸与阅读位置恢复。首页、归档和漫游已有真实封面或关系图，沿用已有视觉表达；阅读版式保持。

## 版本与截图

基线源码 d8a2bbb，正式域名 a-znk.com。

- v0：改动前，1440×1100 浅色；topics/research/concept/topic-about为内容区截图，papers为视口。
- v1：首轮实现，1440×1100桌面与390×1000手机、浅/暗色。过长元素截图中可能拍进粘性顶栏，不是内容叠层；此版还发现作者02标题低于03、横幅图框留白过多。
- v2：修正标题顺序和横图高度、概念索引去重复小方框。桌面用1440×1800容纳完整内容区，并将目标区置于顶栏下方；手机为真实390×1000视口截图。
- production：正式部署后的回读截图，发布后追加。

原图保持完整，保留扫描图本色；Astro按320/640/960生成响应式展示图。本地资源源码哈希及各版本截图哈希保存在captures.json。

145项单测、Astro check/build通过。首轮定向39项中38通过；1项由测试把题签文字误当heading造成，改为检查带可访问名称的参考区后该项通过。随后修正作者图文顺序/横图比例/概念索引，17项相关回归全部通过，包括原图decode、多图切换、Enter/Esc、焦点与滚动恢复、无JS原图入口、手机深色及减少动态。既有文章封面viewer、主题顺序/1100px断点、阅读卡片与论文首条位置在首轮通过。

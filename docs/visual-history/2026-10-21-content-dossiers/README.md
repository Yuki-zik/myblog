# 内容档案视觉版本

目标：回应作者项目／关注区仍是普通列表，以及上一轮只在部分页面加图的问题。共同的纸面、编号与内容层级由 ContentDossier 管理，图片可选。

| 版本 | 来源 | 内容 |
|---|---|---|
| v0 | 正式站 `a-znk.com`，源代码基线 `d5e89f0` | 作者项目与关注、首页近期文章、归档、论文主体改动前 |
| v1 | 本分支首次集成，1440×1800，浅色 | 四个主体区域；暴露项目留白和论文空图片列 |
| v2 | 本分支视觉反馈后的修订 | 作者侧题签、论文正文满宽、首页内容、归档首屏比例 |
| v3 | 本分支候选及手机复核 | 论文压缩题签保持首屏、归档完整原图、手机与深色截图；发现手机标题孤字 |
| v4 | 手机断行修订 | 标题平衡断行、短摘要优化，移除无内容的节标题元信息列；源文字和字号保留 |

`v0` 桌面视口为 1440×1500，后续主版本使用 1440×1800，以保留完整内容区；各截图文件名标明页面、视口类别和主题。截图按版本追加，先等待字体与可见图像解码。

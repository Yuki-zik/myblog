# 顶部胶囊导航恢复

2026-10-18。用户要求保留原顶部栏胶囊设计。本次恢复已经存在的胶囊表面、连续滚动收拢与内容内边距，让首页、主题、文章和论文使用同一导航几何；drawing属性继续提供白纸/橙色配色。

## 修正依据

旧胶囊代码和同一控制器一直保留，drawing覆盖把表面圆角、材质、阴影及伪元素清空，并将内容拉宽到视口边缘。滚动96px时，表面宽1120px但内容向两侧各溢出120px。移除这些覆盖后，沿用原26px连续曲率圆角、柔和阴影、玻璃纸面与26px内容内边距。导航、搜索和主题按钮继续使用原节点与状态机。

实际截图又发现移动端正常滚动时，48px表面只覆盖第一行，两行导航底部超出22px。移动表面现跟随完整内容高度，内容上下各8px；减少动画模式保留静止几何。390px下正常滚动的底部留白13px，减少动画时8px；320px两行导航也完整可见。只有表面scale/translate跟随滚动，内容文字不被缩放。

胶囊恢复后仍保留原图纸页面、橙色索引、文章浮动纸面与新阅读字级。文章/论文选择的drawing标记、正文锚点、TOC、旁注和大图挂载点不变。

## 中文标题链接回查

顶部栏发布后，真实手机目录回查发现旧旁注监听器将编码后的中文fragment直接传入querySelector，虽然标题能跳转，但触发了脚本异常。改为解码fragment并用getElementById查找目标，仅对旁注执行原有flash。3项既有移动目录测试加入pageerror断言后先失败；修后118单测、4项目录/旁注/评论验收通过。胶囊的PR及合并CI均190/190，片段修复的最终发布检查待追加。

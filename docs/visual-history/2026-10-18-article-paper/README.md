## 本轮设计

恢复文章主体与背景的明度及阴影层次；桌面复用覆盖主文和旁注的统一纸面，目录留在纸面外侧。≤1280px继续单栏，在文章自身恢复承载面，保留原有旁注流。

封面从180px放大至最多280px，完整显示原图，使用细白边、小圆角和低透明度柔和投影；减少运动时保持静止。保留白/深纸色、橙标注、正文尺度和所有阅读控制器。

# 英文旁注缺失与定位修复

## 真实故障与上一轮漏检

用户提供英文注释排版截图后，从正式版本 b6afd53 复现：三个英文长文页面的注号分别为10、8、5个，旁注全部为0，正文仍含原始GFM脚注区。页面的水平溢出始终为0。因此先前只检查语言/SEO、链接和页面溢出的双语验收不足，不能证明阅读结构正确。

根因：`rehypeTufteFootnotes` 仅把 `/content/posts/` 识别为文章；`/content/en/posts/` 未进入提取旁注、回写Astro frontmatter、重定向注号、移除正文脚注区的路径。

独立补查还发现绝对定位旁注在脚本初始化前没有布局退化，会叠放。旧JS的1101px阈值也与CSS的1281px浮动旁注阈值不一致。

## 修复边界

只扩展已支持的中英文章路径；主题、概念、论文保留自己的脚注机制。保留脚注键、正文段落锚点、原文内容、引用链接和中文排版。

旁注默认采用正常文流；CSS声明浮动布局适用条件，控制器在同一帧设置模式和全部测量位置。禁用JavaScript或初始化尚未完成时，所有注释仍可阅读，注号的原生链接仍有效。无JS时返回按钮仍为原有非增强行为，本次不宣称完整脚本交互可用。

`pnpm i18n:check` 新增：译文和原文的脚注键一致；每个注号都指向一条且仅一条旁注；重复引用允许；正文不得残留重复脚注区或Footnotes目录项；图注/旁注的译文段落锚点必须真实存在。

## 实图审查发现的第二个回归

第一版正常文流退化通过了“注释之间不重叠”，实图仍发现桌面无JS时注释覆盖跨栏封面（`v1-rejected-nojs-cover-overlap.png`）。最终退化方式改为阅读区域之后的第二个网格行。新增逐注检查与标题/封面、评论、翻页区域的相交，并要求未启用浮动的桌面注释位于文章之后。此缺陷修正前不合并PR。

# A-Znk 全站视觉系统

统一基线是既有建筑线稿首页：纸面、橙色标记、细分隔线、清晰内容层级。适用首页、主题及详情、论文及详情、归档、作者、概念、知识图谱、404、搜索、页脚与阅读辅助界面。

## 共享契约

- 色彩：亮橙 `--drawing-accent` 用于图形标记，深橙 `--drawing-accent-ink` 用于浅色纸面上的小字；深色模式用更亮的橙色墨水。`--link`、`--brand-accent`、按钮、焦点与选中态均在根级声明，避免子节点覆盖主色而继承已求值的旧蓝色别名。
- 字体：导航、标题、元信息使用 `--font-ui`；编号和短题签使用 `--font-mono`；正文保留 `--font-reading`；真实代码及公式保持其语义字体。统一视觉不意味着所有文本使用同一字体。
- 页面：内页共享80rem上限与桌面40px外侧留白，小屏16px；索引类标题使用 `--type-index-title`。首页姓名作为封面保留大字，论文及文章长标题保持阅读页专属度量。
- 控件：导航胶囊保留原圆角与毛玻璃，普通卡片/输入采用细线与2px圆角。内容导航操作采用首页同款底线文字链接；表单主按钮保留可读的实色语义样式。键盘焦点必须清晰可见。
- 动效：保留导航流式收拢、反向恢复、移动两行96px占位，以及搜索关闭时精确恢复阅读位置；内容交互使用轻微位移，尊重减少动态效果设置。

## 保留边界

文章目录、边缘旁注、阅读进度、评论、引用锚点、封面原图与放大交互不改。图谱星空是数据展示区域，节点类型色与社交平台标识色保留；外层框架与页面控件遵循共享系统。favicon暂不重设计。

## 验证与证据

`src/styles/siteIdentity.test.ts` 防止旧蓝色token和默认旧导航回流。
`tests/e2e/site-style-system.spec.ts` 覆盖11类页面、1440/390px、浅色/深色，核验同一导航、链接与操作色、4.5:1墨水对比度、无横向溢出、标题语义与卡片/操作形状，并保存44张浏览器截图。既有滚动、搜索、阅读、内容与发布测试持续运行。

视觉版本位于 `docs/visual-history/2026-10-18-style-unification/`。实际验收结果以后续记录为准，截图/构建通过不代表搜索引擎已收录。

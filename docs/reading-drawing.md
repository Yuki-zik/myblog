# 阅读页：边缘标注与元数据优先

2026-10-17，用户明确选择先前真实内容预览中的两版，并要求实际截图调整后上线、保留各版本视觉。入口页的前期依据见 [设计研究](drawing-discover-design.md)，本轮截图见 [视觉档案](visual-history/2026-10-17-reading/README.md)。

## 实施边界

- 文章正文内容、段落锚点、脚注及旁注DOM、目录控制器和三栏布局保持原有职责。正文保留18.24px/1.88及既有响应式阅读宽度。
- 白/深纸面沿用resolved color scheme；细线与橙色用于章节、导航和引用。宽屏支持封面置于标题旁，窄屏回到文档流，移除阅读页的大卡片光晕。
- 论文详情使用680px主列与230px发表/引用侧栏，桌面标题38px、手机30px，正文18px/1.85。完整作者、发表状态、真实资源、摘要、正文及可选来源明确的封面保留；Cite使用可聚焦的原生锚点，BibTeX保留native details。
- `reading-drawing.css`只配置reading+drawing的纸面与主题语义；`article-drawing.css`和`paper-drawing.css`分别通过`data-reading-design`限定作用范围。不改Markdown插件、旁注控制器或段落/脚注契约，不新增依赖或外部服务。

## 验证方式

新4项阅读验收先在旧构建上失败，再实现。旧默认胶囊导航的专属几何测试迁至仍使用该导航的作者页；阅读页继续测试真实header状态机、目录吸顶/跟随、脚注和旁注。原有圆卡/光晕美学断言改为已批准的平面、紧凑封面，不放宽正文尺度、内容完整性和滚动行为。

视觉备份按v0正式旧版、v1候选、v2本地实现、v3线上验收记录。审查真实长标题、代码块、表格与旁注，检查桌面/手机和浅/深主题；截图不能替代滚动、焦点和内容一致性验收。

## 真实截图促成的修正

1. 第一版白纸上的行内代码继承旧浅色前景，实测对比度仅约1.07:1。保留该版本截图后增加明暗代码对比度验收，再将行内前景映射到正文墨色；代码块继续使用Shiki配对的背景与语法色，避免只改底色破坏高亮可读性。
2. 390px手册目录点击后，标题落到视口上方约578px。原逻辑先计算滚动位置，40ms后折叠目录，导致正文移动而目标过期；1240px还存在CSS显示目录、JS不收起的断点差异。新增390/1024/1240px真实点击与落点验收均先复现失败，然后仅调整现有`toc-client`顺序：先同步折叠，再测量并滚动；移除重复断点和定时器。桌面目录、旁注与脚注算法不变。
3. 手机表格截图仍残留旧暖色卡片阴影，移除该阴影以保持平面图纸边界，表格内容、字号与列布局不变。

初始本地全量检查中的旧封面位置/纸面断言按批准设计更新；默认导航几何检查继续保留原阈值，使用已有稳定态helper等待宽度过渡真正结束。语法色测试改对准站内实际存在的手册代码块，未降低对比度阈值。

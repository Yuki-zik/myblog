# 有序的非对称构图

用户反馈：归档海报被放进方形白框，年份下方出现长空栏；作者实践标题独占一列，四张重复宽卡片令剩余空间显得机械。沿用白纸、橙色和已有内容，以构图解决这些问题。

## 参考与判断

[Cooper Hewitt 对 Armin Hofmann 海报的解读](https://www.cooperhewitt.org/2018/08/05/aharmonyofcontrasts/)将网格、非对称构图和对比元素的统一联系起来；[MoMA 对 Jan Tschichold 1930 年海报的馆藏说明](https://www.moma.org/collection/works/7292)强调非对称与平衡服务于信息传达。这里借鉴其构图思想，保留博客自己的颜色、内容与阅读目的。

据此采用的规则：字体、颜色、编号和对齐网格固定；宽窄、起点与内容自然高度可以变化。变化有重复规则，不依赖随机数、逐条手工定位或任意旋转。

## 落地

- **归档海报**：使用 PostCover 的 `poster` 变体，读取原始图片宽高；图像与容器同宽同高，无白边、方框或额外背景。保留原图、柔和投影和轻微悬停；键盘焦点单独保持可见。
- **时间结构**：年份作为横向章节头和真实年度篇数，月份和内容共享整个版心，不再预留贯穿全年条目的左栏。年月与文章仍按既有数据倒序排列。
- **实践与关注**：章节标题移到内容上方。实践区采用12列网格，按7/5、5/7重复；右侧纸面下移24px，形成有界的疏密变化。关注便笺沿用7/5分配，长研究问题获得较宽版面。
- **阅读秩序**：DOM、键盘顺序和源文字保持。850px及以下回到单列，取消错位；没有为对齐而设置标题占位或固定卡高。

## 覆盖扩展：2026-10-22

用户指出上面的首轮只处理了实践/关注与归档年份，研究方向仍有长标题空栏。此次把构图从局部选择器提升为发现页共用的内容网格，并明确检查实际主体，而不是只给少数卡片加偏移。

| 页面 / 区域 | 内容角色与安排 |
|---|---|
| 作者研究方向 | 章节头横向占满版心，第一研究方向为全宽图文；其余方向宽窄配对，图与文字保持真实比例及自然高度 |
| 作者写作、项目与关注 | 同一配对网格，写作共用主题详情的 PostCard 内部排版；取消只承载节标题的长空栏 |
| 主题目录 | 7/5、5/7 循环；最后单项跨满；窄项完整文字与原比图版分别获得有效空间 |
| 全部五个主题详情 | 入口文章全宽，其余文章配对；只有一篇时完整使用版心，避免半屏空置 |
| 首页近期文章 | 首项全宽，后续配对；日期/主题移至横向题签，取消占据正文宽度的独立元数据栏 |
| 归档月份 | 月内多条配对，单篇跨满；时间先后和年度/月度层级不变，窄记录采用正文在前、原图随后 |

覆盖的实际路由为首页、作者、归档、主题目录与五个主题详情，共9页。首页建筑首屏、轮播、漫游工作区与挂板、论文元数据和文章阅读系统继续保持各自的内容角色，不将同一网格机械铺到所有界面。

共享规则在 `editorial-rhythm.css`：`data-editorial-grid="paired"` 以7/5、5/7循环；`lead` 先给首项完整宽度，再进入配对。孤立末项自动跨满，不留空位。桌面偏移24px；1100px及以下回到单列，取代首轮实践区独有的850px边界。标题、正文、图片均按自然高度排列，不用固定等高或随机位置凑形状。

首轮截图发现：若宽卡横排、窄卡提前上下排图，会制造新的大块空白。因此共享阅读卡和首页近期的桌面配对统一内部图文方向，手机才纵向排列。目录窄项的图版也不能压进120px固定高槽；改为原比图像与并列图注，使横向示意图能够被辨识。图像是否好看、文字是否好读，优先于网格形式本身。

这是一组可复用的规则，不为某一条项目写专用版式。新增项目依然填写 `SITE_AUTHOR_PROFILE.practiceHighlights`，新增文章从 collection 自动接入，宽窄循环随条目自然延续。

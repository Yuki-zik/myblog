## 数据与时间

- `src/data/agent-history.json` 是本次审阅后的公开摘要，不存放原始聊天、个人路径、会话标识或凭据。

- 显示与按日理解统一使用 `America/Los_Angeles`，不把机器的中国时区或 UTC 日期直接当成报告日期。`reviewedAt` 是本次整理时间。

原来的 `src/data/agent-observatory.json`、`acceptedTasks`、并发/人工/返工口径保持独立。当前没有足够起止事件或人工计时，因此仍为空；没有将消息间隔、工具执行、等待时间、会话总跨度或累计 Agent 名单换算成工时和并发。
